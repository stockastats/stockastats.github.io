📊 Bienvenue sur StockaStats

Site d'articles centralisant des contenus provenant d'autres dépôts Git.

À propos

Ce site agrège des articles et analyses statistiques publiées sur différentes plates-formes, les compilant dans un espace centralisé pour faciliter la lecture et le partage.

🚀 Workflow rapide

  1. Cloner un dépôt source localement
  2. Récupérer un fichier Markdown/Quarto à publier
  3. L'importer dans articles/ avec le script d'import
  4. Lancer quarto render
  5. Pousser le dossier docs/ sur main pour GitHub Pages
